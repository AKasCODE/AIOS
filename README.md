# AIOS

A personal AI Operating System inspired by Jarvis.

## Features
- Chat with LLMs
- FastAPI Backend
- Modular Architecture
- OpenRouter Integration
- Logging
- Error Handling

## Tech Stack
- Python
- FastAPI
- OpenRouter
- Pydantic
- Uvicorn

## Project Structure

AIOS/
├── app/
├── core/
├── services/
├── models/
└── ...

## Installation

1. Clone repository
2. Create virtual environment
3. Install dependencies
4. Add .env
5. Run uvicorn
